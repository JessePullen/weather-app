# To Do List

## About the Project

This is a Weather App project as part of "The Odin Project". The "Visual Crossing" weather API is used to return weather information for the chosen location.
There is an icon that changes based on the weather condition, as well as a day and night theme based on local time of the location.

## Skills Practiced

-   Using an API to fetch weather information.
-   Async/Await and Try/Catch for API implementation and error handling.
-   Dynamic icons/theme based on returned information.

## How to Run the Project

The project can be viewed in the web browser on GitHub Pages at the following link: https://jessepullen.github.io/weather-app/
